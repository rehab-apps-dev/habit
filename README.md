# 習慣スタンプ帳

習慣を定着させるための、自分用のスマートフォン向けWebアプリ（PWA）です。
できた日に判子を押す「スタンプカード」形式で記録します。

## 使い方
- 公開URL：https://rehab-apps-dev.github.io/habit/
- スマートフォンでURLを開き、「ホーム画面に追加」するとアプリとして使えます。
- 記録はスマートフォンの中だけに保存されます（サーバーには送信しません）。

## 主な機能
- 習慣の登録（きっかけ → すること の If-then プラン）
- つまずいた時の対処計画と「最低ライン」の設定
- 今日のチェック、週ごとの達成回数、月のカレンダー表示
- 週1回の振り返り（自動化度：SRBAI 4項目・7段階）と8週間の推移
- 抜けた翌日の立て直しメッセージ、週・月初めの再スタート表示
- 記録の書き出し・読み込み（バックアップ）

## ファイル構成
| ファイル | 役割 |
|---|---|
| index.html | アプリ本体（画面・見た目・動き） |
| manifest.webmanifest | アプリ名・アイコン・全画面表示の設定 |
| sw.js | オフラインでも動かすための仕組み（サービスワーカー） |
| icon-192.png / icon-512.png / apple-touch-icon.png | ホーム画面のアイコン |

## 設計の根拠
- Gollwitzer & Sheeran (2006)：If-thenプラン（実行意図）の効果
- Lally et al. (2010)：習慣の自動化までの中央値は約66日、1日の抜けは影響が小さい
- Gardner et al. (2012)：同じ状況での繰り返し／SRBAI（習慣の自動化尺度）
- Sniehotta et al. (2005)：つまずいた時の対処計画
- Harkin et al. (2016)：進み具合の記録が目標達成を促す
- Dai, Milkman & Riis (2014)：フレッシュスタート効果
